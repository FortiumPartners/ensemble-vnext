## Summary

Makes `/rebase-project` fast by moving every deterministic part of a rebase (copying framework files, removing retired ones, merging `.claude/settings.json`, stamping the version) into one script call, so the model only resolves the conflicts the script reports and writes the readout. The plan measures today's rebase on a drifted fixture first, builds the engine, rewrites the prompt onto it, then measures again on the identical fixture and reports before and after.
