## Summary

Makes the functional-verification loop fix failures in a targeted loop and prove the result with one full run at the end (GitHub issue #113). Every unmet result is first sorted into a build defect, a missing capture or a check this host cannot run, and only build defects are fixed. After each fix, only the criteria with that cause are re-checked; one full regression pass at the end is the proof. A must-pass criterion this host cannot check becomes a visible accepted gap that custody can accept at ship, only material failures block, and follow-ups list product items first.
