## Summary

Moves Ensemble's per-feature run records (the `.trd-state/<feature>/` files that describe a run, not the product) off the feature branch and onto one git ref per feature, `refs/ensemble/records/<slug>`, so they stop reaching `main` with every merge. A new library writes the ref by compare-and-swap and pushes it best effort, falling back to a branch commit where the ref cannot be pushed; readers learn to fall back to the ref; every records commit is replaced by a ref write, with the worktree copy git-ignored; the detached ship record folds into the ref; `/rebase-project` cuts existing projects over; a final task proves the whole path on a fixture project.
