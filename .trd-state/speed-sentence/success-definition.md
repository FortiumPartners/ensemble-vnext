**On evidence for prompts.** A prompt is often assembled at dispatch time rather than stored as one file, so a grep of the source tree may not show where it ends. The best evidence is the prompt text as actually dispatched in an after-run (the subagent transcript's first message), or the output of the code that assembles the prompt, run at the measured commit. A grep hit on a template is the fallback. It is weaker, because it shows the text exists but not that it is the last thing in the assembled prompt. A claim should say which kind of evidence it carries.
