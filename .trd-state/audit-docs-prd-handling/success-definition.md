**Not carried as a criterion:** source lines 48-51 ("each test below asserts on a fixture where
the old code produces the wrong output") constrain how the tests are written, not what the
product does. They are honoured above by making every row's evidence a fixture on which the
pre-change code gives the wrong result; a separate row would only restate that.

**A criterion carrying a `Parts` count cannot pass incrementally.** None of the rows above
carries one.

**Exercise limit worth knowing in advance:** FS-8 to FS-11 and FS-18 describe what the review
agent and the command are instructed to do. Their target evidence is the instruction text,
because a live `/audit-docs` run needs a model session. A judge may reasonably rule the text
alone as proof of the instruction rather than of the agent obeying it; a live-run PRD diff
settles that where one is available.
