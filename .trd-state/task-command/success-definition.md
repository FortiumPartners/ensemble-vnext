## How to read this definition

- **No live sessions.** `/task` is a Markdown command prompt executed by a model. No row requires starting a `claude` session. Every row is proven from files on disk in one of two ways:
  - **Text rows.** The artifact is the command file itself — `packages/core/commands/task.md`, and its vendored mirror `.claude/commands/task.md`, which must carry the same instruction — and the locator is the instruction found in it. A text row proves the instruction is written down, not that a live run obeys it; read a `met` on such a row as no more than that.
  - **Fixture rows.** Run the libraries the command tells the model to use — `.claude/lib/implement-state.js` (`save`, `recordResult`, `checkpoint`) and `.claude/lib/artifacts.js` (`record`, `get`) — against a temporary fixture directory, with exactly the arguments `task.md` directs, capture the output and read back the resulting `implement.json` / `artifacts.json` to a file. If `task.md` does not direct a library call for that step, the fixture row cannot be exercised as written and that is itself the finding.
- **`closed.json` has no writer library.** Nothing under `.claude/lib/` writes it [read]. Its shape is proven from the template or field list in `task.md`.
- **Rows marked `judge-only`** are ones only a live run can prove: a run reaching its banner. The reason is in the cell, along with the file evidence a judge would accept in place of the run.
- **Where the source is silent, no row asserts.** For example, the source does not say how many steps a brief should become ("a short step list"), how long a slug may be, or what publishing-off looks like beyond "publishes them when publishing is on". No row invents a figure for any of these.
