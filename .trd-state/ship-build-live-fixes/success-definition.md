## Lines considered, no row written

- **Actual 8, "Nothing in any shipped string waits for CI on the merge commit."** It could be
  read as asking for the default and example strings to gain a `wait-ci` after `merge`. Expected
  8 asks only that a `wait-ci` placed after `merge` behave correctly, so no criterion requires
  the shipped strings to change. `.claude/rules/ship.md` is owner-governed in any case, so a row
  there would point a debugger at a file no autonomous run may edit.
- **"posts" in Expected 1.** Whether a review actually appears on a GitHub PR cannot be shown
  here: no GitHub environment is listed in `verification.md` §1. FS-1 covers the cause the
  source names (the reviewer refused every `gh` call); FS-2 covers recognising the review once
  it is posted.

No credential value appears in this file: FS-6 names the secret by name (`ANTHROPIC_API_KEY`),
never its value.
