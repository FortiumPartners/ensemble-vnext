"Custody" here is the ship-time check (`custody.js reconcile`) that compares the shipped code against the commit the verification run was anchored to, and fails when shipped code changed after verification. The scenario in FS-1 to FS-5 is the reproduction's own (line 5): `src/a.js` changed on the feature branch at the anchor; `main` then adds `src/c.js` and changes `src/b.js`; the feature branch merges `main` and commits `.claude/verification-notes.md`; reconcile runs.
