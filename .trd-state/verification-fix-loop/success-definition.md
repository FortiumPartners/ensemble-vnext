and the libraries behind them. There is no HTTP surface or browser. "Functional" here means what a
user sees when invoking the commands, what lands on disk (state files, reports, discovery rows,
scaffolded skills), and what the deterministic libraries return when called directly with fixtures.
Where a criterion is about model-driven command behaviour, its evidence names the real proof (a run)
and the nearest static evidence (the command or skill text that instructs it), in that order.
