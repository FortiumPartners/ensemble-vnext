# Files the framework itself writes: shared per-session working state that
# differs on every branch and so clashes at merge time. Per-feature state under
# .trd-state/<feature>/ is not listed here, with these exceptions: each
# feature's dispatch log (per-session working state like the shared one), and
# the bulky per-run scratch of the verification loop (evidence/, findings/,
# judge-*, record-* and setup-decide-* files). That scratch is reproducible by
# re-running the loop and holds no decision.
#
# Records (closed.json, implement.json, reports, the shared session log...) live
# on the feature's ref, refs/ensemble/records/<slug>, not on the branch; the
# last lines below ignore them so they stop appearing as changes. Ignoring does
# not untrack: removing the copies already tracked is /rebase-project's cutover.
# Lines after the marker are written to .gitignore only, never untracked.
